# Privacy policy for Zod

Zod is a personal, non-commercial assistant built for a university course project (USC CSCI 599). It is operated by one person, its owner, for use with one dedicated test Google account. It is not offered to the public.

## What Zod accesses
With the owner's consent, Zod requests these Google permissions for the dedicated test account only:
- Read Google Calendar events (calendar.events.readonly).
- Read Gmail messages (gmail.readonly).
- Create Gmail drafts (gmail.compose). Zod never sends email on its own.

## How the data is used
Data is used only to answer the owner's own requests (for example a calendar summary or an email digest) and to prepare drafts the owner reviews. It is not used for advertising, profiling or any other purpose.

## Storage and sharing
- Data is stored only in the owner's own Google Cloud project (a private database and bucket).
- Data is not sold, shared with third parties, or used to train AI models.
- Private content (calendar and email) is processed by a model running on the owner's own laptop. If that model is unavailable, the request is held rather than sent to a cloud AI provider.

## Retention and deletion
Data stays in the owner's project until the owner deletes it. The Google authorization can be revoked at any time at https://myaccount.google.com/permissions, and deleting the project removes all stored data.

## Google API Services User Data Policy
Zod's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
